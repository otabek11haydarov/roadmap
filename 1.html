🔢 Keith Galli & Fluent Python Konteksti

Nima uchun NumPy oddiy Python Listdan 50–500x tez?

  • 1. Fixed Data Types: Python list har bir element turini ishlash vaqtida tekshiradi (dynamic type checking). NumPy esa yagona qat'iy tur (masalan, int32 yoki float64) saqlaydi.
  • 2. Contiguous Memory: List elementlari RAMda tarqoq pointerlar orqali bog'lanadi; NumPy ndarray esa xotirada uzluksiz ketma-ket bloklarda joylashadi (CPU Cache locality).
  • 3. SIMD Vectorization & GIL: NumPy C/Fortran kodlari Python GIL (Global Interpreter Lock) ni bo'shatadi va protsessorning SIMD vektor registrlarida barcha elementlarni parallel hisoblaydi.

🐼 Pandas Docs & Senior Scaling Konteksti

Split-Apply-Combine va Zero-Copy Xotira

  • • Split-Apply-Combine: Pandas groupby() ma'lumotni mezon bo'yicha ajratadi (Split), har bir guruhga funksiya qo'llaydi (Apply) va yangi jadvalga birlashtiradi (Combine).
  • • Copy-on-Write & Memoryview: Fluent Python (Travis Oliphant iqtibosi) va Pandas 3.0 hujjatlarida ko'rsatilganidek, memoryview va PyArrow katta jadvallarni baytlardan nusxa ko'chirmasdan (zero-copy) ulashadi.
  • • Dask Parallelization: Bitta kompyuter RAMiga sig'maydigan datasetlar Dask yordamida klasterlar bo'ylab parallel Pandas/NumPy bloklariga bo'linadi.
